# 扇贝浮窗 (ShanbayLens)

一个 Android 小 App：你在扇贝单词里背单词时，它实时读出屏幕上正在显示的那个词，然后在**悬浮窗**里按你给的模板把讲解铺出来。

不是扇贝官方功能，纯个人学习用的辅助工具。

---

## 一、先说清楚能力边界

**能做到**

- 无障碍读屏取词：翻到下一个词，浮窗自动跟着换，延迟 ~0.7 秒（可调）
- 截屏 OCR 兜底：无障碍读不到时，切 OCR 通道，只截屏幕上半部分本地识别
- 悬浮小圆球：可拖动，点一下展开/收起；面板高约占屏幕 62%，里面是滚动的完整讲解
- 讲解内容 100% 按你的模板生成（模板已内置，可整段替换）
- 本地缓存：同一个词第二次看秒出，不重复花钱
- 「一句话记忆」自动进剪贴板：讲完把核心搭配 + 例句压成纯文本复制出来，换词时自动清掉上一条
- 候选词纠正：识别不准时，面板顶部会列出 2~6 个候选，点一下就换成那个词
- 换词：面板里直接手打任意单词讲解

**做不到 / 要注意**

- **iOS 做不了**。苹果不允许第三方 App 全局悬浮窗，这个方案只在 Android 成立。
- 扇贝的「句中挖空 / 拼写测试」模式里，单词可能被隐藏或打码，读屏和 OCR 都抓不到，只能手动输入。
- 「实时」是界面变化触发，不是视频级实时；翻卡瞬间会有半秒左右延迟。
- 讲解是**每次调用大模型现生成**的，一个词按你的模板出来通常 2000~4000 字，耗时 5~20 秒，看你选的模型。不是本地词典那种秒出。
- 我没法把 App 直接接到「我」这个会话的模型上——我没有可外发的 API Key。所以模型要你自己填一个（下面有免费方案）。

## 二、关于「免费语言模型」

App 支持任何 **OpenAI 兼容**的 `/chat/completions` 接口，内置 4 个预设：

| 预设 | 是否免费 | 说明 |
|---|---|---|
| 智谱 GLM-4-Flash | 免费 | `https://open.bigmodel.cn/api/paas/v4`，注册就有，国内直连，**推荐** |
| 硅基流动 SiliconFlow | 有免费模型 | 部分小模型免费，国内直连 |
| DeepSeek | 按量付费，很便宜 | `deepseek-chat`，质量好 |
| OpenRouter | 有 `:free` 模型 | 需要能访问外网；免费模型列表经常变，去官网挑一个带 `:free` 的填进去 |

**拿智谱免费 Key 的步骤（3 分钟）**

1. 打开 <https://open.bigmodel.cn/>，手机号注册
2. 进「控制台」→「API Keys」→ 新建，复制那串 key
3. 粘到 App 的「API Key」里，点「保存设置」→「测试连接」，看到 `可用 ✓` 就行

> 你的 key 只存在手机本地 SharedPreferences 里，App 只会在你点生成时把它发给上面那家服务商。

## 三、拿到 APK（三种方式，选一种）

### 方式 A：GitHub Actions 云编译（不用装任何东西，推荐）

1. 在 GitHub 新建一个空仓库（Private 也行）
2. 把 `shanbay-lens` **文件夹里面的内容**（不是文件夹本身）传到仓库根目录，见下方说明
3. 进仓库 `Actions` 标签页 → 左侧 `Build APK` → 右侧 `Run workflow` → 绿色按钮
4. 等 3~5 分钟，两种拿法：
   - **手机直接装**：仓库右侧 `Releases` → 最新一条 → 下载 `app-debug.apk`（直接是 apk，不用解压）
   - **电脑**：这次运行页面底部 `Artifacts` 下载 `ShanbayLens-debug-apk.zip`，解压得到 `app-debug.apk`

> **上传要点**：拖进 GitHub 的必须是 `shanbay-lens` 里的 `app/`、`.github/`、`build.gradle`、`settings.gradle`、`gradle.properties` 这些，让它们躺在**仓库根目录**。
> 如果拖完发现多了一层 `shanbay-lens/`，或者根目录没有 `.github`，工作流就不会被识别（GitHub 只认仓库根目录下的 `.github/workflows/`）。
> `.github` 是隐藏文件夹，Windows 资源管理器要勾「显示隐藏项目」才看得见；实在传不上去，就在仓库里点 `Add file → Create new file`，文件名直接输入 `.github/workflows/build-apk.yml`，把内容粘进去即可。

### 方式 B：Android Studio

1. Android Studio 新建 `Empty Views Activity` 项目，**包名填 `com.shanbaylens`**，语言 Java，minSdk 26
2. 用本仓库的内容覆盖：
   - `app/src/main/java/com/shanbaylens/` 整个目录
   - `app/src/main/res/`、`app/src/main/assets/`
   - `app/src/main/AndroidManifest.xml`
   - `app/build.gradle` 里的 `dependencies` 加一行 `implementation 'com.google.mlkit:text-recognition:16.0.0'`
3. 点 Run，或 `Build > Build APK(s)`

### 方式 C：已有 Android 工程直接合并

把 `app/src/main` 下四个目录（`java`、`res`、`assets`、`AndroidManifest.xml`）按同名合并，再补上 ML Kit 依赖即可。包名必须保持 `com.shanbaylens`，否则无障碍服务声明对不上。

## 四、首次配置（照着点，5 步）

1. **装 APK**，打开 App
2. **开无障碍**：点「打开『无障碍』设置」→ 已下载的应用 → 扇贝浮窗 → 打开
   - Android 13+ 如果开关是灰的：先回 App 点一次，然后到「设置 → 应用 → 扇贝浮窗 → 右上角 ⋮ → 允许受限设置」
3. **填模型**：选预设 `智谱 GLM-4-Flash`，粘 API Key，点「保存设置」，再点「测试连接」
4. **回桌面**，打开扇贝单词，进入「背单词」界面
5. 屏幕右侧出现蓝色小圆球 → 翻一个词 → 面板自动弹出讲解

第一次可能会问「允许显示在其他应用上层」——**不需要**，本 App 用的是无障碍浮层（`TYPE_ACCESSIBILITY_OVERLAY`），不走那个权限。

## 五、浮窗怎么用

| 操作 | 效果 |
|---|---|
| 拖动小圆球 | 换位置，记住到下次 |
| 点小圆球 | 展开 / 收起面板 |
| 顶部「重讲」 | 忽略缓存，重新生成（换模型后点这个） |
| 顶部「换词」 | 弹出输入框，手打任意单词讲解；键盘弹出时面板会临时变成可聚焦 |
| 顶部「复制」 | 把整段讲解 markdown 复制到剪贴板 |
| 顶部「×」 | 收起面板 |
| 顶部候选 chips | 识别错词时，点正确的那个 |

底部那行灰字是状态：`生成中 · 1234 字` / `完成 · 8.3s · glm-4-flash · 记忆已复制` / 红色是报错。

### 剪贴板同步：「一句话记忆」自动复制

每讲完一个词，App 会从讲解里把「七、一句话记忆」这一节抽出来，**只保留核心搭配 + 例句（中英对照）**，压成这样的纯文本放进剪贴板：

```
【abandon】
核心搭配：
- abandon a plan
- abandon hope
- abandon oneself to
例句：
- They abandoned the plan.
  他们放弃了这个计划。
- He abandoned his car and ran.
  他丢下车跑了。
```

翻到下一个词时，上一条会被自动清掉——所以你随时长按粘贴，粘出来的都是**当前这个词**的记忆片段，不会串词。

两个开关在设置页「⑤ 剪贴板同步」：

- `自动复制「一句话记忆」的短语与例句`（默认开）
- `换词时清除上一次复制的内容`（默认开）

几个说明：

- **清理范围**：只在「本次运行内 App 确实写过剪贴板」之后才清。但 Android 10+ 后台读不到剪贴板，App 无法确认里面还是不是它写的内容——如果你中途自己复制了别的东西，换词时也会被清掉。介意的话把第二个开关关掉。
- Android 13+ 每次写剪贴板系统会弹一个小预览，属于正常现象
- 少数 ROM 限制后台 App 写剪贴板，如果发现粘出来是空的，先用「复制」按钮手动复制一次，确认这条路通
- 模型没输出「一句话记忆」这一节时不会复制（不会拿别的章节凑数）

## 六、取词方式

**默认：只用无障碍读屏**

原理：`AccessibilityService` 拿到当前窗口的节点树，用一套启发式打分挑出「最像当前单词」的文本节点：

- 控件 id 含 `word/title/head/spell` 加分，含 `sentence/meaning/phonetic/trans` 减分
- 单个英文词加分，多词句子减分；越靠屏幕上方分数越高
- 按钮（可点击）减分，输入框（拼写模式）加分
- 纯中文、带网址、长度异常的文本直接排除

**兜底：截屏 OCR**

点「授权截屏 OCR」→ 系统弹「开始录制或投放」→ 允许。之后每 1.4 秒截一帧，只裁屏幕上半部分（`0~48%` 高度）丢给 ML Kit 离线识别。图片不出设备。

OCR 适合：无障碍拿不到节点（Flutter/游戏化界面、加固过的 WebView）、或你想让它顺带认别的 App 上的英文。

**识别不准怎么办**

1. 面板顶部候选 chips 里点对的词（大多数情况够用）
2. 点「换词」手打
3. 在设置里把「只监听这些 App」改成更精确的包名，减少误触发
4. 把防抖从 700 调到 1200，减少翻卡过程中的中间态误判

## 七、模板

内置模板就是你给的那份「英语单词讲解固定格式」，原文在 `app/src/main/assets/template_default.txt`。

App 把它整段作为 `system` prompt 发出去，`user` 消息只有一句「请按模板讲解这个单词：xxx」。所以你**改模板 = 改输出格式**，不用动代码。

设置页第 ④ 块可以整段编辑、恢复默认、查看全文。改完记得点「保存设置」。

**几个实用调整**

- 输出被截断（结尾突然没了）：把 `max_tokens` 从 4096 调到 8192
- 太慢：模板里「每个义项至少 3 个例句」改成 1~2 个，或直接删掉「一句话记忆」里的 800 字要求
- 模型爱加开场白：模板开头已经写了「不要寒暄」，如果还加，就在模板最前面补一句「直接输出 # 开头的内容，不要任何前置说明」

## 八、常见问题

**Q：开了无障碍，圆球不出现？**
A：设置页顶部状态看是不是「已连接」。如果显示「已开启」但没连上，关掉无障碍开关再打开一次。小米/华为要在「自启动」「后台弹出界面」里放行。

**Q：圆球在，但不换词？**
A：把「取词防抖」调小到 300 试试；再不行切「两者都用」并授权 OCR。还不行就把扇贝界面截图发我，我看下节点结构（`viewId` 是随版本变的）。

**Q：面板一片黑/白屏？**
A：WebView 在某些精简 ROM 上初始化失败。先在设置页点「测试连接」确认网络正常；仍然白屏的话，把 App 的「Android System WebView」更新一下。

**Q：键盘弹不出来（换词时）？**
A：部分 ROM 对 `TYPE_ACCESSIBILITY_OVERLAY` 窗口的输入法支持差。退路：回 App 用第 ⑥ 块「在浮窗里讲这个词」。

**Q：很耗电？**
A：无障碍通道基本不耗电。OCR 通道是持续截屏，建议只在需要时开，用完点「停止截屏 OCR」。

**Q：剪贴板里没有内容 / 粘出来还是上一个词？**
A：先看状态栏有没有「记忆已复制」。没有的话：① 设置里「自动复制」开关是否开着；② 该词的讲解里模型有没有输出「一句话记忆」这一节（模型偶尔会省掉，点「重讲」重试）；③ 部分 ROM 禁止后台写剪贴板，这时只能回浮窗点「复制」手动来一次。

**Q：换词时没清掉上一条？**
A：两种可能：① 你关掉了「换词时清除」；② 该 ROM 的后台 `clearPrimaryClip()` 是空操作，而写空内容的兜底也被系统拦了。前者打开开关，后者把 App 切到前台一次再试。

**Q：会不会误删我自己复制的东西？**
A：会。App 只在本次运行内写过剪贴板之后才执行清理，但它读不到剪贴板内容，没法判断此刻里面是不是它写的。所以如果你习惯一边背单词一边复制别的东西，把「换词时清除」关掉，靠下一次自动覆盖来保证不串词。

**Q：一个词要等十几秒，太慢？**
A：模板本身要求输出极长（7 大节 + 表格 + 十几条例句），慢是必然的。两个办法：换 DeepSeek（快很多）、或把模板精简成「音标 + 3 个义项 + 1 个搭配表」。

**Q：能不能不花钱、不联网？**
A：不能完整实现。要按这份模板生成讲解，必须有语言模型。离线词典（如 ECDICT）只够给「词性 + 中文释义」，给不了例句、同义替换、易混辨析。

## 九、目录结构

```
shanbay-lens/
├─ .github/workflows/build-apk.yml   # 云端编译 APK
├─ settings.gradle / build.gradle    # AGP 8.5.2 + Gradle 8.7
└─ app/
   ├─ build.gradle                   # minSdk 26 / targetSdk 34 / ML Kit
   └─ src/main/
      ├─ AndroidManifest.xml
      ├─ assets/template_default.txt # 你的讲解模板（原文）
      ├─ res/xml/accessibility_service_config.xml
      └─ java/com/shanbaylens/
         ├─ MainActivity.java        # 设置页
         ├─ ShanbayA11yService.java  # 读屏 + 浮窗宿主
         ├─ WordFinder.java          # 从节点树里猜当前单词
         ├─ OverlayController.java   # 圆球 + 面板 + 流式渲染
         ├─ OcrCaptureService.java   # 截屏 OCR 通道
         ├─ LlmClient.java           # OpenAI 兼容流式客户端
         ├─ MarkdownLite.java        # 自写 markdown → HTML
         ├─ MemoryClip.java          # 抽「一句话记忆」+ 剪贴板生命周期
         ├─ Html.java                # WebView 外壳与样式
         ├─ WordCache.java           # 本地缓存
         └─ Prefs.java               # 配置与默认模板
```

## 十、隐私与合规

- 只读取屏幕上「看起来像英文单词」的文本，不采集账号、密码、学习记录
- 截屏只在设备内做 OCR，图像不落盘、不上传
- API Key 存在本机，只发给你自己配置的模型服务商
- 生成结果缓存在 App 私有目录，卸载即清
- 请仅用于个人学习，不要用于批量抓取扇贝词库或商业分发；也不要违反扇贝的用户协议
